Consultas Básicas

Primeros pasos para obtener información

SELECT

- SELECT: se utiliza para recuperar datos de una tabla y seleccionar que datos en especifico quieres.
Ejemplo: SELECT Nombre, Edad FROM Alumno;

WHERE y LIMIT

- WHERE: filtra registros según una condición. Ejemplo: SELECT * FROM Alumno WHERE Edad > 18;
- LIMIT: restringe la cantidad de registros devueltos. Ejemplo: SELECT * FROM Alumno LIMIT 5;

AND/OR

- AND / OR: permiten combinar condiciones en una consulta. Ejemplo: SELECT * FROM Alumno WHERE Edad > 18 AND Ciudad = 'Buenos Aires';
