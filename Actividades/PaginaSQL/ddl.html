Definición de Datos (DDL)

Comandos para estructurar la base de datos

CREATE

El comando CREATE se utiliza para crear nuevas estructuras en la base de datos, como tablas, vistas o bases completas. Este comando define los campos y sus tipos de datos, estableciendo la base de la organización de la información. Ejemplo:
CREATE TABLE Alumno (ID INT PRIMARY KEY, Nombre VARCHAR(50), Edad INT);

ALTER

El comando ALTER permite modificar la estructura de una tabla existente. Se puede usar para agregar, eliminar o cambiar columnas, así como para modificar restricciones. Con este comando se adapta la base de datos a nuevas necesidades sin tener que eliminar la tabla completa. Ejemplo:
ALTER TABLE Alumno ADD Correo VARCHAR(100);

DROP

El comando DROP elimina por completo una tabla o base de datos. Es un comando poderoso y debe usarse con precaución, ya que borra toda la información y estructura asociada. Se utiliza principalmente cuando una tabla ya no es necesaria o debe ser reemplazada. Ejemplo:
DROP TABLE Alumno;
