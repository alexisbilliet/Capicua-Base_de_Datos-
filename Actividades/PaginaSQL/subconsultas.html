Subconsultas

Consultas dentro de otras consultas

Subconsulta en WHERE

Una subconsulta puede usarse en la cláusula WHERE para comparar valores. Ejemplo: SELECT Nombre FROM Alumno WHERE Edad > (SELECT AVG(Edad) FROM Alumno);

Subconsulta en FROM

Una subconsulta puede actuar como una tabla temporal en FROM. Ejemplo: SELECT Sub.Ciudad, COUNT(*) FROM (SELECT Ciudad FROM Alumno) AS Sub GROUP BY Sub.Ciudad;

Subconsulta en SELECT

También se puede usar en la lista de columnas de SELECT. Ejemplo: SELECT Nombre, (SELECT MAX(Nota) FROM Inscripciones WHERE AlumnoID = Alumno.ID) AS NotaMax FROM Alumno;

Subconsulta con IN

Una subconsulta puede devolver un conjunto de valores para usar con IN. Ejemplo: SELECT Nombre FROM Alumno WHERE CursoID IN (SELECT ID FROM Curso WHERE Profesor = 'Juan');
