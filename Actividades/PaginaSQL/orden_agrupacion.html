Orden y Agrupación

Organizar resultados en SQL

ORDER BY y ASC/DESC

- ORDER BY: se utiliza para ordenar los resultados de una consulta según una o varias columnas.
Ejemplo: SELECT Nombre, Edad FROM Alumno ORDER BY Edad;
- ASC / DESC: definen el orden ascendente o descendente. Ejemplo: SELECT Nombre, Edad FROM Alumno ORDER BY Edad DESC;

GROUP BY y COUNT

- GROUP BY: agrupa registros que tienen valores iguales en una columna.
Ejemplo: SELECT Ciudad, COUNT(*) FROM Alumno GROUP BY Ciudad;
- COUNT: devuelve el número de registros en cada grupo. Ejemplo: SELECT CursoID, COUNT(*) FROM Inscripciones GROUP BY CursoID;

HAVING y SUM

- HAVING: filtra los resultados de un GROUP BY según una condición.
Ejemplo: SELECT Ciudad, COUNT(*) FROM Alumno GROUP BY Ciudad HAVING COUNT(*) > 5;
- SUM: devuelve la suma de valores en un grupo.
Ejemplo: SELECT CursoID, SUM(Nota) FROM Inscripciones GROUP BY CursoID;
