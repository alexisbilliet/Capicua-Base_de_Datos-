Manipulación de Datos (DML)

Comandos para trabajar con la información

INSERT

El comando INSERT se utiliza para agregar nuevos registros a una tabla. Ejemplo: INSERT INTO Alumno (ID, Nombre, Edad) VALUES (1, 'Juan', 20); Este comando permite cargar datos iniciales o añadir información nueva a medida que la base de datos crece.

UPDATE

El comando UPDATE sirve para modificar registros existentes en una tabla. Se utiliza junto con la cláusula WHERE para indicar qué registros deben actualizarse. Ejemplo: UPDATE Alumno SET Edad = 21 WHERE ID = 1; Con este comando se pueden corregir datos, actualizar información o reflejar cambios en la realidad.

DELETE

El comando DELETE elimina registros de una tabla. Al igual que UPDATE, se recomienda usar la cláusula WHERE para especificar qué registros borrar. Ejemplo: DELETE FROM Alumno WHERE ID = 1; Si se omite WHERE, se eliminarán todos los registros de la tabla, aunque la estructura de la tabla permanecerá intacta.
