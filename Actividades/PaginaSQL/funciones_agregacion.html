Funciones de Agregación

Operaciones simples para resumir datos

COUNT y SUM

- COUNT(): cuenta la cantidad de registros.
Ejemplo: SELECT COUNT(*) FROM Alumno;
- SUM(): suma los valores de una columna numérica.
Ejemplo: SELECT SUM(Nota) FROM Inscripciones;

MIN y MAX

- MIN(): devuelve el valor mínimo de una columna.
Ejemplo: SELECT MIN(Edad) FROM Alumno;
- MAX(): devuelve el valor máximo de una columna. Ejemplo: SELECT MAX(Nota) FROM Inscripciones;

AVG

- AVG(): calcula el promedio de una columna.
Ejemplo: SELECT AVG(Edad) FROM Alumno;
