b. ¿ Puedo usar Limit 1 con Order by para reemplazar el MAX? Justificar en
cualquiera de los 2 casos y dar un ejemplo.

Si se puede utilizar cuando quieres tener un registro del valor maximo o alto.
El limit 1 se puede usar cuando quieres obtener el registro con valor máximo y el Max() cuando solo quieres calcularlo o solo para obtener el valor numerico.
Ejemplo;


Con Max()
select max(salario) as salario_maximo 
from empleados;
