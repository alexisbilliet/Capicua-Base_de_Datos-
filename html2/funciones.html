Funciones SQL

Las funciones SQL permiten realizar diferentes operaciones sobre los datos de una tabla.

Algunas funciones permiten contar registros o calcular valores.

Count

Count se utiliza para contar la cantidad de registros que cumplen con una consulta.

Ejemplo:

Select Count(*) From Alumnos;

Avg

Avg se utiliza para calcular el promedio de los valores de una columna.

Ejemplo:

Select Avg(Edad) From Alumnos;

Max y Min

Max permite obtener el valor mas alto y Min permite obtener el valor mas bajo de una columna.

Max
Select Max(Edad) From Alumnos;
Min
Select Min(Edad) From Alumnos;
Estas funciones permiten obtener informacion de los datos sin tener que revisar cada registro manualmente.
