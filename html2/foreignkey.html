Foreign Key

Foreign Key significa clave foranea. Se utiliza para relacionar una tabla con otra dentro de una base de datos.

Una Foreign Key normalmente hace referencia a la Primary Key de otra tabla.

¿Para que sirve?

Sirve para relacionar los datos de diferentes tablas y mantener una relacion entre ellas.

Ejemplo

Una tabla Alumnos puede tener un ID_Curso que indique a que curso pertenece cada alumno.

Create table Alumnos (
ID_Alumno int primary key,
Nombre varchar(30),
ID_Curso int,
Foreign Key (ID_Curso) references Cursos(ID_Curso)
);

Relacion entre tablas

En este ejemplo, ID_Curso de Alumnos es una Foreign Key que hace referencia a ID_Curso de Cursos.

Cursos

ID_Curso → Primary Key

Alumnos

ID_Curso → Foreign Key
