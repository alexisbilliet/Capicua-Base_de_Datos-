Joins

Los Joins se utilizan para relacionar informacion de diferentes tablas en una misma consulta.

Para relacionar las tablas se utiliza una columna que tengan en comun.

Inner Join

Inner Join muestra solamente los registros que tienen una coincidencia entre las tablas.

Ejemplo
Select Alumnos.Nombre, Cursos.Nombre
From Alumnos
Inner Join Cursos
On Alumnos.ID_Curso = Cursos.ID_Curso;

¿Para que sirve?

Permite obtener informacion relacionada que se encuentra separada en diferentes tablas.

Tabla Alumnos

Contiene informacion sobre los alumnos.

Tabla Cursos

Contiene informacion sobre los cursos.

Inner Join permite combinar la informacion de estas dos tablas cuando tienen un dato relacionado.
