Bases de datos

Una base de datos es un lugar donde se puede guardar y organizar informacion de manera ordenada.

SQL permite trabajar con la informacion almacenada dentro de una base de datos.

¿Para que sirven?

Las bases de datos sirven para guardar grandes cantidades de informacion y poder buscarla o modificarla cuando sea necesario.

Ejemplo

Una escuela podria tener una base de datos con informacion sobre sus alumnos, profesores y cursos.

Cada tipo de informacion puede estar organizada en diferentes tablas.

Ejemplo de una base de datos

  • Alumnos
  • Profesores
  • Cursos
  • Materias
