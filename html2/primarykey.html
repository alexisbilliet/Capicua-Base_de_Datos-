Primary Key

Primary Key significa clave primaria. Se utiliza para identificar de manera unica cada registro de una tabla.

Una Primary Key no puede repetirse dentro de la misma tabla.

¿Para que sirve?

Sirve para diferenciar los registros y poder identificar cada uno de ellos de forma sencilla.

Ejemplo

En una tabla de alumnos, el ID_Alumno puede ser la Primary Key porque identifica a cada alumno.

Create table Alumnos (
ID_Alumno int primary key,
Nombre varchar(30)
);

Ejemplo de registros

ID_Alumno Nombre
1 Juan
2 Lucas
3 Agustin
