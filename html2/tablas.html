Tablas

Las tablas se utilizan para organizar la informacion dentro de una base de datos.

Una tabla esta formada por filas y columnas.

Filas y columnas

Las columnas representan los diferentes datos que queremos guardar, mientras que las filas representan los registros.

Ejemplo

Una tabla de alumnos puede tener columnas como Nombre, Apellido y Edad.

Cada alumno ocuparia una fila diferente.
